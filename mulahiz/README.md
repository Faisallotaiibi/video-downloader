# ملاحظ

أداة شخصية تساعدك على تحضير مسودات "ملاحظات مجتمع" (Community Notes) على X بسرعة واحترافية.

ارفع صورة سكرين شوت لتغريدة (أو الصق نصها/رابطها)، والتطبيق:

1. يقرأ محتوى التغريدة (نص + وصف أي وسائط مرفقة) عبر Claude Vision
2. يحدد الادعاء المحتاج تحقق
3. يبحث حياً على الإنترنت (Claude + أداة web search) ليتحقق من الادعاء ويجمع مصادر موثوقة
4. يعرض ملخص البحث والمصادر
5. يصيغ مسودة ملاحظة جاهزة بالعربية الفصحى، محايدة، مع مصدر موثوق ورابطه، وعداد أحرف حي قابل للتعديل

التطبيق **لا يرسل** أي شيء تلقائياً إلى X — فقط يجهّز المسودة لتراجعها وتنسخها وتقدّمها بنفسك.

## التشغيل

```bash
cd mulahiz
npm install
cp .env.example .env
# ثم ضع مفتاح ANTHROPIC_API_KEY في ملف .env
npm start
```

افتح `http://localhost:3000`.

## ملاحظة مهمة عن حد الأحرف

القيمة الافتراضية لحد أحرف الملاحظة (`DEFAULT_NOTE_CHAR_LIMIT` في `.env`، والحقل القابل للتعديل في الواجهة) مضبوطة حالياً على **280 حرفاً**، وهو الحد المعروف لملاحظات المجتمع على X. لم يتمكن هذا البناء من الوصول إلى communitynotes.x.com/guide مباشرة للتحقق من الرقم الحالي بسبب قيود شبكة بيئة التطوير، لذا **تحقق من الرقم الفعلي هناك قبل الاعتماد الكامل عليه** — يمكنك أيضاً تعديله يدوياً من حقل "حد الأحرف الأقصى" في شاشة النتيجة في أي وقت.

## البنية

```
mulahiz/
  server/
    index.js          نقطة الدخول (Express)
    routes/
      read.js          POST /api/read    قراءة التغريدة (رؤية Claude)
      verify.js         POST /api/verify   التحقق عبر بحث الإنترنت
      draft.js           POST /api/draft    صياغة المسودة + حفظها في السجل
      history.js          GET/PUT/DELETE /api/history
    lib/
      anthropic.js       عميل Anthropic + أدوات مساعدة لاستخراج JSON من الردود
      prompts.js          البرومبتات الداخلية (القيود: الحياد، عدم اختلاق مصادر، تفضيل المصادر الأولية)
      storage.js           تخزين السجل في data/drafts.json
  public/                الواجهة (HTML/CSS/JS بسيط، بدون إطار عمل)
  data/drafts.json       سجل المسودات (يُنشأ تلقائياً، مستثنى من git)
```
